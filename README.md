# Novira Mobile App Dark Prototype

Static GitHub Pages prototype for the Novira dark-theme mobile customer dashboard.

Live entry point: `index.html`

Included screens:

- Dashboard
- Trackers
- Tracker details
- Shipments
- Shipment details
- Fleets
- Drivers
- Alerts
- Notifications
- Widgets
- Reports
- Subscriptions
- Support tickets
- Support ticket details
